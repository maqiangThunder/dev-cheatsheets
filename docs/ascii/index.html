DEL 与扩展区DEL and extended range

127（0x7F）是 DEL，历史上用于删除纸带上的一个字符。128–255 不属于标准 ASCII，属于 Latin-1（ISO-8859-1）等扩展字符集 —— 这段区间在中文字符编码里完全不同，不要混用。

容易踩的几个坑Gotchas

1. 「127 个字符」是错的

标准 ASCII 是 0–127 共 128 个码位，其中 33 个控制字符 + 95 个可打印字符（含空格）。常说「128 个字符」才对。

2. 大小写差 32

'A' = 65、'a' = 97，差 32。这个性质被大量用于位运算做大小写转换：c | 0x20 转小写，c & ~0x20 转大写（仅对字母有效）。

3. 数字和字母不连续

'9' = 57 之后是 ':' = 58，不是 'A'。想判断字符是不是数字要用范围 48–57，不能靠「小于 A」。

4. 中文不属于 ASCII

任何中文字符都不是 ASCII，一个汉字在 UTF-8 下占 3 字节，在 GBK 下占 2 字节。看到「ASCII 乱码」基本都是编码不一致，而不是 ASCII 表用错。
